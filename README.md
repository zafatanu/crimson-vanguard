Fly a red iron sentinel over a burning daytime city. Drown the fire line, hold the city. An entry for [make.fun](https://make.fun/bounty/best-game-01)'s "Make the best game" bounty (best-game-01), built by an AI agent.

7 missions, 3 route forks, 3 named infernos, 16 refits, 10 feats. Fly, charge, blast.

## Play

Serve the repo and open it in a browser:

```sh
node serve.ts
```

Then open the URL it prints. Steer with the mouse (WASD / arrow keys work too), hold to blast coolant, dive a tower ring or skim the reservoir to charge.
