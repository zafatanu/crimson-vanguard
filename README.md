Aerial firefighting action game for the [make.fun](https://make.fun) best-game-01 bounty: fly a red iron robot over a burning city, dive through coolant towers to refill the tank, and blast the fire lines out.

Open the playable HTML in this repo in a browser to play — no build step needed.
